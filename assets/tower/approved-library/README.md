# AlanTil 17.2 — единственная актуальная библиотека башни

Содержит утверждённые модели и рецепты. Никакая другая папка не используется редактором кладок или игрой.

- `index.json` — единый каталог: 10 авторских секций, ворота v9, дверь и окно.
- `sections/` — десять оригинальных JSON-рецептов. Их геометрия и локальные трансформации не изменяются автоматически.
- `common100/` — единственный GLB со 100 исходными камнями и его JSON-манифест.
- `architecture/` — GLB ворот, двери, окна и четырёх элементов сопряжения.
- `../materials/balkaria-stone-v2.1/` — светлая охристая каменная PBR-текстура.

**Текущий формат построек:** `17.7-approved-manual.1` для кладок и утверждённые версии архитектурных модулей. В старых сохранениях нет поддержки. Старая библиотека `prefabs/` не должна возвращаться.

Игровой код: `src/features/tower/`; редактор кладок: `src/features/masonry/`; расчёт размещения: `packages/tower-game/`.

Проверка: `node --test scripts/qa/approved-library.test.mjs tests/tower-approved-manual.test.mjs`.
