# AlanTil 17.2 · единая библиотека утверждённых секций

Эта папка — **единственный источник новых каменных секций и архитектурных GLB** для ручного редактора и игрового каталога.

- `index.json` — один реестр (10 авторских JSON + ворота v9, дверь, окно), размеры, идентификаторы и SHA-256.
- `sections/` — десять исходных авторских JSON без изменения ни одного байта, включая 2×2×2 v3 и 3×3×3 v2. Форматы `common100-manual-1` и `common100-mixed-2` поддерживаются.
- `common100/` — оригинальные 100 каменных мешей и их исходный манифест. Геометрия камней, ориентации и масштабы из JSON не исправляются автоматически.
- `architecture/` — утверждённые ворота v9, каменная и деревянная двери, каменное и деревянное окно, четыре исходных GLB стыков окна.

Новые секции в игре сохраняются с `geometryVersion='17.7-approved-manual.1'`; уникальная пара `sectionId` + `variant` выбирает одну из 10 рецептур. Архитектурные модули сохраняют прежние идентификаторы и версии для совместимости старых башен.

**Архив, не удалять:** старый `assets/tower/prefabs/manifest.json`, все `assets/tower/prefabs/**`, старые `assets/tower/sections/manual-common100/**`, композитные библиотеки `compact-stone-*.glb` и истории базы. Они используются для отображения ранее построенных секций. Скрытие устаревших вариантов из каталога **не означает** удаление их данных или геометрии. Размеры `2×2×3` и `4×4×4` пока доступны только в архиве, до подготовки авторских версий.

Проверка: `node --test scripts/qa/approved-library.test.mjs`. Интеграция сохраняет первоначальные `id`, координаты, повороты, размеры и опоры существующих башен. Источники проверяются по SHA-256; при несоответствии библиотека отвергается, а не восстанавливается из процедурных кубов.
