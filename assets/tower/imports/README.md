# AlanTil 17.5.5 — загрузка новой кладки из библиотеки 71 камня

Исходный архив: **AlanTil_25_Masonry_GLB_Only.zip**, SHA-256:
`e9499604f4ad15c87aa1a25442a7c18accc0731ec4bf5109d55a33835a08136c`.

Возможность прямого импорта больших локальных GLB в GitHub Connector отсутствует.
Чтобы установить ровно 25 утверждённых полноразмерных моделей, нужно загрузить
три части данного ZIP (каждая меньше лимита GitHub Web UI 25 МБ) в ЭТУ папку
ветки `agent/masonry-71-1755-20261016`:

- `AlanTil_25_Masonry_GLB_Only.zip.part00` (20 MiB)
- `AlanTil_25_Masonry_GLB_Only.zip.part01` (20 MiB)
- `AlanTil_25_Masonry_GLB_Only.zip.part02` (~17 MiB)

GitHub Actions `tower-71-import.yml` сверяет SHA-256 исходного ZIP, распаковывает
**полноразмерные** 25 GLB (не мобильные упрощённые preview), проверяет 25 различных
имён, материалы и отсутствие длинных А/Б моделей, переносит в
`assets/tower/prefabs/masonry-71-*-17_5_5.glb`, и удаляет части ZIP из репозитория.

Не сливать рабочую ветку `17.2` и не применять серверную миграцию, пока не
будут загружены все GLB, пройдены SQL/Node/браузерные тесты и CI.
Новые установки используют `17.5.5`, старые сохранения продолжают
использовать их старые 17.5.2/17.5.3/17.5.4 модели.
Плотность укладки 31–57%, это пока визуальный пилот, а не полная 90–95% забутовка.
