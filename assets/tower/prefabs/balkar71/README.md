# AlanTil 17.5.5 — компактные секции

В каталоге хранятся **два** файла одной геометрической версии:

- `library-wall-17_5_5.glb` — 63 уникальных камня, геометрия и UV без повторений (3 334 300 байт).
- `placements-17_5_5.json` — 25 схем размещения, 913 камней (125 890 байт).

Получить оба файла можно из `AlanTil_1755_Compact_2_Assets.zip`, подготовленного в чате.

До загрузки этих файлов **нельзя** переключать новые установки на `geometryVersion: 17.5.5`.

Исходные модели `17.5.4` и старые сохранения не удалять.
