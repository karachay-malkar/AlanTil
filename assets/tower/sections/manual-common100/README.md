# Ручные секции Common 100 (отдельный каталог)

Здесь хранятся **только утверждённые к внесению в исходники пользовательские расстановки**. Это отдельный источник, не связанный с автоматически собранными секциями башни.

## Файлы

- `index.json` — версионированный реестр ручных секций, размеры, число камней, SHA-256.
- `section-3x3x3-v1.json` — оригинальный пользовательский экспорт «Секция 3×3×3», 86 камней, 3×3×3 ячейки (0,75 м по каждой оси).
- `section-1x1x1-v1.json` — первый вариант секции 1×1×1, 6 камней MAIN, без изменений.
- `section-1x1x1-v2.json` — второй вариант секции 1×1×1, 8 камней (5 MAIN + 3 CHINKING), 0,25×0,25×0,25 м, самостоятельный исходник.
- `section-2x2x2-v1.json` — оригинальная ручная секция 2×2×2, 11 камней (9 MAIN + 2 CHINKING), 0,50×0,50×0,50 м, отдельный исходник.
- `section-2x2x2-v2.json` — второй вариант 2×2×2, 19 камней (2 LARGE + 9 MAIN + 8 CHINKING), исходный экспорт без изменений.
- `section-2x3x4-v1.json` — первый вариант 2×3×4, 40 камней (37 MAIN + 3 CHINKING), исходный экспорт без изменений.
- `section-2x3x4-v2.json` — второй вариант 2×3×4, 40 камней (35 MAIN + 5 CHINKING), оригинальный экспорт `common100-mixed-2` без архитектурных объектов, без изменений.
- `src/features/masonry/manual-sections/registry.mjs` — загрузчик/валидатор, используемый ручным редактором.

Исходные пользовательские экспорты сохранены **байт в байт**, включая все записи `{id,name,position,quaternion,scale}`, без округления, нормализации, смены имён или удаления камней.

## Как пользоваться

Раздел **Практика → Редактор кладки**. В списке «Новая секция» появляется группа **Ручные секции проекта** с отдельными вариантами `1×1×1 v1`, `1×1×1 v2`, `2×2×2 v1`, `2×2×2 v2`, `2×3×4 v1`, `2×3×4 v2`. Выбор исходника загружает камни из `common-100.glb` в исходных координатах, без привязки к сетке и обрезания выступов. Сохранение в Supabase создаёт **отдельную редактируемую копию**, а исходный JSON остаётся неизменным.

## Как добавить следующие секции

1. Получить полный экспорт редактора формата `common100-manual-1` или `common100-mixed-2` (для ручных каменных секций поле `architectures` должно быть пустым).
2. Проверить идентификаторы/повороты/масштабы и сверить `librarySha256` с библиотекой Common 100.
3. Создать новый JSON-файл в этой папке (оригинал не изменять).
4. Дописать уникальный `id`, `file`, `cells`, `stoneCount`, `counts`, `sha256` в `index.json` и обновить версию запроса каталога при необходимости.
5. Запустить `node --test scripts/qa/manual-common100-sources.test.mjs`.

**Важно:** загрузчик этого каталога не подключён к действующему `src/features/tower/prefab-scene.js`, старому `assets/tower/prefabs/manifest.json` и сохранению башен. Интеграция в игровое строительство — отдельное решение после проверки и утверждения кладки.
