# AlanTil 17.5 — approved prefab-only tower

Baseline: 17.4.1. Branch: 17.2. Project feature: `/practice/tower`.

## Architecture

- Five prefab sizes, 25-cm integer-cell world grid: 1×1×1, 2×2×2, 2×2×3, 2×3×4, 4×4×4.
- Eight **pre-baked** original-rock alternatives for each size. No browser-time stone placement, deformation, or packing.
- Only pre-authored original-source stones (`assets/tower/source-original-36.glb`) are used to create geometry.
- Diffuse, normal and ARM PBR textures come from the project's existing `assets/tower/rock_07/textures` source.
- Irregular angular stones, staggered courses, moderate exterior relief, medium amounts of irregular chinking, no generated cuboid fillers.
- Gameplay requests a destination from camera aim or touch; 25-cm *grid only* snapping, NO magnetic translation along a neighbour.
- Grid appears on ground and hit face during positioning, disappears in select/view mode.
- Rotation: yaw 0/90/180/270 only.
- Prepared shared-edge interface, tiled prepared joins for horizontal/vertical faces and a dedicated right-angle corner connector; no runtime mesh scaling for new joints.
- Free building of hollow towers, walls, corners and openings. Entire footprint must be supported; no 35/49 partial support shortcut.
- Preview stays locked after explicit selection; both preview and placement use identical coordinates, bounds and support validation.
- Eight visual alternatives supported now, library representation is extensible to twelve without schema changes.
- Local unpaid draft only. No server V3 writes or wallet mutations before future price approval. Paid V1/V2 remains readable and unchanged.

## Geometry versioning and backward compatibility

- New GLBs: `*-17_5.glb`, manifest version `17.5.0`, each section stores `geometryVersion`.
- Old GLBs `section-*-v0..v3.glb` and `joint-{x,y,z}.glb` stay intact.
- Legacy 17.4.1 local draft sections without a stored geometry version are assigned `17.4.1` on reading; they continue to use their original GLBs. Unrestorable old support cases stay visible as read-only drafts rather than silently discarded.
- Old purchased V1/V2 snapshots only load; purchase RPC calls are not invoked in this release.

## Main changed modules

- `tools/tower/build-prefab-library.py`: preservation of authored proportions, offline packing and chinking, glTF UV/PBR export, 8x5 versioned library, immutable connector assets.
- `packages/tower-game/prefab-layout.mjs`: integer 25-cm grid, exact union-of-supporting-rectangles coverage, rotation-aware occupied volumes.
- `packages/tower-game/prefab-joints.mjs`: compatibility resolution and ready-made face/corner stone tiles.
- `src/features/tower/{index.js,prefab-scene.js,tower.css}`: draft flow, scene, grid visuals, no wallet changes.
- `src/app/router.js`, `src/shared/styles/lazy/tower.css`: scoped cache-version bump, no other navigation changes.
- Tower CI/tests: 40 assets, PBR and geometry checks, unsupported-placement and grid tests, browser WebGL screenshots.

## Measurement note

The offline occupancy metrics use convex envelope proxies sampled on a 12.5-mm grid. They do **not** prove absence of all visible voids, photorealistic appearance, watertight union of differently authored neighbouring meshes, or 15–25% visual chinking on every face. Browser screenshots and manual visual comparison with the approved natural wall remain necessary for final aesthetic acceptance. Automatic tests must not be reported as aesthetic approval.
