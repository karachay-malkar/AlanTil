# AlanTil 16.4 Foundation Parity

Reference: Web 13.15.12.

Release gate:
- Web and Mobile consume shared platform-independent algorithms.
- Mobile runtime dictionary is loaded through the Web dictionary contract (`v_words_app`, `content_stories`, `dictionary_metadata`).
- `mobile/AppRoot.js` does not construct runtime `WORDS` from `STARTER_DICTIONARY`.
- Account progress, favorites and settings retain the shared merge/queue policies.
- `docs/WEB_ORIGIN_16_4.json` is the provenance manifest.
- `mobile/tests/web-origin-parity-16-4.test.mjs` must pass.
- `MOBILE_REIMPLEMENTATION` must equal 0.

Platform-only code is limited to native transport/persistence concerns such as OAuth deep links, AsyncStorage, React Native lifecycle and REST transport.
