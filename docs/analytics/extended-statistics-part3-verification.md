# Расширенная статистика 16.8 — часть 3: месячная регулярность

Статус: COMPLETE

## Контракт

- Учитываются только полностью завершённые календарные месяцы UTC.
- Для каждого человека считается число уникальных активных дней в месяце.
- График показывает абсолютное число людей с активностью не менее 1, 3, 7, 14 и 28 дней.
- `d1` одновременно является числом уникальных людей, заходивших в приложение за месяц.
- Проценты и дробные коэффициенты не используются.
- Person identity совпадает с частью 2: авторизованный `user_id`, стабильный guest `visitor_id`, объединение guest → account при однозначной связи.

## Реализация

RPC `admin_extended_analytics` строит `month_person_days` из дедуплицированных `visit_days`, исключает текущий месяц условием `vd.day < v_current_month`, затем агрегирует пороги `d1`, `d3`, `d7`, `d14`, `d28`. `month_series` заканчивается предыдущим календарным месяцем.

Web UI `monthlyVisitorsChart` отображает пять абсолютных серий из `monthly_visitors`.

## Проверяемые инварианты

- один человек в один день не увеличивает `active_days` больше чем на 1;
- человек с 7 активными днями входит в d1, d3 и d7, но не входит в d14/d28;
- текущий незавершённый месяц отсутствует в `monthly_visitors`;
- месяцы без активности внутри диапазона возвращаются с нулями, а не исчезают;
- график не использует проценты.
