# AlanTil 16.8.0.5 — Ashyk room recovery

Base: agent/16.8.0, f80c6fc8bcdc156b18cfc5deb4594a1e326142b9.

## Changes

- Shared waiting/playing reconciliation: Ready retries every 1 second; heartbeat every 3 seconds during play; failure backoff up to 5 seconds. RPC timeout: 8 seconds.
- Room Realtime and private Broadcast recreate failed channels with 0.5–8 second backoff; disposed channels cannot reappear.
- Broadcast is attached only in playing. Both connection states participate in the UI and interaction lock.
- Local waiting stays waiting. Old revisions/phases cannot regress an accepted room snapshot.
- Dictionary loading runs alongside room restoration. No old friends-snapshot prerequisite. Failed dictionary loads expose retry. Ready is deferred until vocabulary is available.
- Restored waiting clients reset their persisted readiness through ashyk_room_not_ready while vocabulary loads. Already playing matches are not paused by a reconnect.
- Challenge/Accept/Resume acquire an immediate operation lock before awaiting build checks or RPCs. Lost invite/accept responses recover the server's active room.
- Build freshness check is cached for this page session and runs in the background.
- Initial field settles in scheduled batches before Challenge; no 900-step click handler.
- Late session replies cannot reopen rooms after destruction; failed shot-result retries yield for one second.
- New migration restores 13 complete canonical functions and two guards, and adds the authenticated member-only readiness reset. Historical migrations remain unchanged.
- Runtime rebuilt exclusively by tools/ashyk-web/build.mjs. Web build/cache version: 16.8.0.5.

## Deployment order and limits

1. Apply supabase/migrations/20260926021946_alantil_16_8_ashyk_connection_recovery.sql to the AlanTil database after the existing single-room migration. This is a complete transactional SQL file, not snippets.
2. Publish this Web build (16.8.0.5); rebuild Mobile to include its changes.
3. Verify Challenge → Accept → playing on two signed-in devices; interrupt/reconnect each network in waiting and playing.

Production AlanTil database was not accessible through the connected Supabase projects. Its definitions could not be compared with the repository and this migration was NOT applied there. Local PostgreSQL tests use real migration functions with isolated auth/friendship fixtures; they do not verify production RLS or actual WebSocket delivery. No physical-device or native bundle run was performed. No deployment or remote push was performed by this change.

Optional integration dependencies: @electric-sql/pglite@0.3.14, react@19.1.0, react-test-renderer@19.1.0. Install them into a separate QA directory and set ASHYK_SQL_TEST_DEPS and ASHYK_REACT_TEST_DEPS to its absolute path before running the new tests. Without these environment variables the SQL execution and React integration tests are explicitly skipped.
